# تطبيق Just Start - إبدأ الآن (Flutter Android Project)

مشروع تطبيق **Just Start - إبدأ الآن** متكامل ومبني بإطار **Flutter**، مصمم بهوية الشعار والمنشورات الرسمية (**البنفسجي الملكي `#6D28D9` والأزرق الكهربائي `#0099FF`**)، ويعمل بالكامل محلياً بدون خادم سحابي (Zero-Backend) مع التحويل المباشر للطلبات عبر **واتساب، فيسبوك، والبريد الإلكتروني**.

## 2. خطوات تشغيل المشروع واستخراج ملف الـ APK للأندرويد
1. فك الضغط عن مجلد المشروع وافتحه باستخدام **VS Code** أو **Android Studio**.
2. افتح الطرفية (Terminal) داخل المجلد ونفّذ الأمر التالي لتحميل الحزم:
   ```bash
   flutter pub get
   ```
3. (اختياري) لتوليد أيقونة الهاتف الرسمية وشاشة الإقلاع الأصلية من الشعار تلقائياً:
   ```bash
   dart run flutter_launcher_icons
   dart run flutter_native_splash:create
   ```
4. لتجربة التطبيق مباشرة على هاتفك أو المحاكي:
   ```bash
   flutter run
   ```
5. لاستخراج ملف التثبيت النهائي (`APK`) خفيف الحجم ويعمل على جميع أجهزة الأندرويد:
   ```bash
   flutter build apk --split-per-abi
   ```
   ستجد ملف الـ APK الجاهز للتثبيت والنشر في المسار:
   `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk`

## 3. كيف تضيف منشوراً أو دورة جديدة مستقبلاً؟
افتح الملف `lib/data/just_start_data.dart` فقط (وهو المقابل المباشر لملف `js/posts.js` في موقعك) وأضف عنصراً جديداً داخل قائمة `services` أو `courses` أو `posts`.
